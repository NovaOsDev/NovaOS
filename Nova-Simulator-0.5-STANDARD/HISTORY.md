## 2026 — Beginning of Nova

Nova began as an experimental operating-system project. Early versions focused on booting a custom kernel, framebuffer graphics, a grid-style desktop, windows, and mouse input.

### NovaOS 0.3.1
An early bootable kernel prototype. It displayed the Nova graphical environment and was tested in VirtualBox.

### NovaOS 0.4 experiments
Development focused on window dragging, mouse input, cursor rendering, and window controls. These experiments showed that low-level input and graphics development would slow down rapid interface prototyping.

### Nova Simulator 0.1
The simulator branch was created so the Nova interface could be developed much faster while keeping the real NovaOS kernel project separate.

The first simulator introduced a boot sequence, login screen, desktop, movable windows, a files prototype, and Nova Browser.

### Nova Simulator 0.2
Nova became more OS-like with local user setup, password login, a lock screen, taskbar, Start menu, quick settings, improved files interface, Settings, Terminal, and notifications.

### Nova Simulator 0.3
Project identity and development records were formalized. README, history, changelog, credits, and creator information were added so Nova's development has a clear documented history.

---
Nova continues as both a real OS experiment and a desktop simulator/prototyping project.

### Nova Simulator 0.4
Nova introduced the Owner PC concept. The creator profile can access a dedicated Owner Console and developer controls that are hidden from standard Nova users. This establishes the first prototype of Nova's role and privilege system.
