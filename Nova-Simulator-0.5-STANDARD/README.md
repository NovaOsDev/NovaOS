# Nova Simulator 0.5

Desktop/OS interface prototype created by **Samuel.Vieaira.Rodrigues**.

## Official build
- Version: **0.5.0**
- Variant: **Standard PC**
- Build ID: **NOVA-050-STD**
- Project started: **2026**

## Features
Boot and login experience, Nova desktop, Start menu, taskbar, movable windows,
Nova Browser, Files prototype, Settings, Terminal, quick settings, notifications,
and separate Owner/Standard builds.

## Running
Install Node.js, extract the project, then run `START-NOVA.bat`.
On first launch npm installs Electron.

## Important
Nova Simulator runs on Windows through Electron; it is not the bootable NovaOS kernel.
Use only a test password in the simulator. Never reuse a real account password.
