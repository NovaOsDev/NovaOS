# LARP Demo PWA v0.1

Installierbare Demo-Web-App für simulierte Sales-Dashboards und Benachrichtigungen.

- Anzahl der simulierten Verkäufe festlegen
- Zeitraum und Startzeit wählen
- Mindest-/Höchstbetrag festlegen
- gleichmäßige, zufällige oder wellenartige Verteilung
- geplante Aktivität und simulierten Umsatz anzeigen
- App-Badge, wenn unterstützt
- Demo-Mitteilungen

Alle angezeigten Umsätze und Bestellungen sind Simulationen.
